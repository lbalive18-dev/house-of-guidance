Take it with you

Install when your browser supports it

These are web apps, so you can always use them in a browser. Installation depends on each app’s setup and your device. If no install option appears, continue using the app in your browser.

Android

  1. Open the app in a supported browser.
  2. Open the browser menu.
  3. Choose Install App or Add to Home Screen if shown.
  4. Follow the prompts.

Desktop

  1. Open the app in a supported browser.
  2. Look for an install option in the address bar or menu.
  3. Select Install if available and follow prompts.
  4. Otherwise, use it in your browser.
